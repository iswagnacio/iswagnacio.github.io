Part 1.1: Convolutions from Scratch!

Implementation Overview

This section implements 2D convolution in four-loop and two-loop versions, and compares performance and boundary handling with scipy.signal.convolve2d.

1. Implementation Approaches

Four-Loop Implementation

The most straightforward approach using nested loops over image dimensions and kernel dimensions:

def convolution_four_loops(image, kernel):
    img_h, img_w = image.shape
    kernel_h, kernel_w = kernel.shape
    pad_h = kernel_h // 2
    pad_w = kernel_w // 2
    padded_image = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant', onstant_values=0)
    
    output = np.zeros_like(image)
    
    for i in range(img_h):
        for j in range(img_w):
            for ki in range(kernel_h):
                for kj in range(kernel_w):
                    output[i, j] += padded_image[i + ki, j + kj] * kernel[ki, kj]
    
    return output

Two-Loop Implementation

More efficient approach using vectorized operations for the inner kernel loops:

def convolution_two_loops(image, kernel):
    img_h, img_w = image.shape
    kernel_h, kernel_w = kernel.shape
    pad_h = kernel_h // 2
    pad_w = kernel_w // 2
    padded_image = np.pad(image, ((pad_h, pad_h), (pad_w, pad_w)), mode='constant', constant_values=0)
    
    output = np.zeros_like(image)
    
    for i in range(img_h):
        for j in range(img_w):
            region = padded_image[i:i+kernel_h, j:j+kernel_w]
            output[i, j] = np.sum(region * kernel)
    
    return output

Part 1.3: Derivative of Gaussian (DoG) Filter

Noise Reduction through Gaussian Smoothing

By combining Gaussian smoothing with derivative operators, we can significantly reduce noise while preserving important edge information. This section explores two equivalent approaches: sequential convolution (blur then differentiate) versus single convolution with Derivative of Gaussian (DoG) filters.

1. Gaussian Filter Construction

We construct 2D Gaussian filters using cv2.getGaussianKernel() to create a 1D Gaussian, then taking the outer product to obtain the 2D version:

gaussian_1d = cv2.getGaussianKernel(kernel_size, sigma)
            gaussian_2d = gaussian_1d @ gaussian_1d.T

Gaussian Formula: G(x,y) = (1/2πσ²) × e^(-(x²+y²)/2σ²)

Where σ controls the amount of smoothing - larger σ values create more blur.

Original Cameraman Image

Gaussian Blurred (σ=1.7)

2. Derivative of Gaussian (DoG) Filters

DoG filters combine Gaussian smoothing with differentiation in a single convolution operation by convolving the Gaussian filter with finite difference operators:

dog_x = convolve2d(gaussian_2d, Dx, mode='same')  # DoG-X filter
dog_y = convolve2d(gaussian_2d, Dy, mode='same')  # DoG-Y filter

Mathematical Equivalence: ∂(G * I)/∂x = (∂G/∂x) * I

Due to the associative property of convolution, we can pre-compute the derivative filters.

Part 2.1: Image "Sharpening"

1. Mathematical Foundation

Step-by-Step Process:

  1. Apply Gaussian blur: Blurred = Gaussian_Filter * Original
  2. Extract high frequencies: High_Freq = Original - Blurred
  3. Enhance and add back: Sharpened = Original + α × High_Freq

Single Convolution Equivalent: The entire process can be combined into one convolution with the unsharp mask kernel: K = (1 + α)I - αG, where I is the identity kernel and G is the Gaussian kernel.

Parameters

  • σ (sigma): Controls Gaussian blur amount - smaller values target finer details
  • α (alpha): Sharpening strength - higher values create more dramatic enhancement

Configuration: σ = 0.6, α = [0.5, 1.0, 1.5, 2.0]

5. Key Observations and Analysis

How Unsharp Masking Works:

  • Frequency Separation: Gaussian blur acts as a low-pass filter, leaving high frequencies in the difference
  • Detail Enhancement: Adding scaled high frequencies back enhances edge contrast and fine textures
  • Perceptual Sharpening: Increased local contrast creates the illusion of sharper edges

Parameter Effects:

  • Small σ (0.6): Targets fine details and textures for enhancement
  • Progressive α: From natural enhancement (0.5) to dramatic effects (2.0)
  • Trade-offs: Higher α values increase sharpening but may introduce artifacts

Part 2.2: Hybrid Images

Hybrid Image Creation

Hybrid images are perceptually fascinating objects that change interpretation based on viewing distance. By combining the high-frequency components of one image with the low-frequency components of another, we create images that appear as one thing when viewed up close and as another when viewed from far away. This technique exploits the human visual system's sensitivity to different spatial frequencies at different viewing distances.

Multiresolution Blending Process

Technical Implementation

  1. Gaussian Stack Construction: Apply progressive Gaussian blur without downsampling, σ = 2^level
  2. Laplacian Stack Creation: Compute bandpass filters as L[i] = G[i] - G[i+1]
  3. Mask Stack Generation: Create Gaussian stack for the blending mask
  4. Frequency-Specific Blending: Blend[i] = L_A[i] × Mask[i] + L_B[i] × (1-Mask[i])
  5. Image Reconstruction: Sum all blended Laplacian levels to create final result
